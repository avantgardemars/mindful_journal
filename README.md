# Mindful Journal

A private, mobile-first static web journal designed for GitHub Pages and the iPhone home screen.

## Deploy to GitHub Pages

1. Create a new GitHub repository (for example, `mindful-journal`). Keep it private if you prefer; check that your GitHub plan supports Pages for private repositories.
2. Upload `index.html` to the repository root and commit the change.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site. The published address will appear in the Pages settings.

## Add to the iPhone Home Screen

1. Open the published Pages address in **Safari** on the iPhone.
2. Tap **Share**.
3. Choose **Add to Home Screen**.
4. Name it `Mindful Journal`, then tap **Add**.

## Data and privacy

- The app is static: it does not send journal entries to a server and has no account or analytics.
- Entries are stored in local browser storage on the device/browser where you use it.
- There is no automatic sync between devices. Use **Tendências → Exportar cópia de segurança** regularly and keep the JSON file somewhere private.
- Clearing Safari/site data can erase local entries. An exported JSON file can be imported again.
- Do not store information here that you would not want someone with access to your unlocked device to see.

## Important note about the calendar

The initial date is set to 28 October 2026 to match the journal start date. The calendar visually alternates days over a 35-day window, but is only a tracking aid—not medical advice or a recommendation to take a substance. Confirm product instructions with the manufacturer and discuss relevant health risks or medication interactions with a qualified clinician.
